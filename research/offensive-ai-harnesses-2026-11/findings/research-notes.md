# Harnesses in the Wild — content of record (as of 2026-11-17; first compiled 2026-09-19)

The page and its machine-readable dataset render from data/ (evidence.json, field.json, sources.json, uses.json); this file holds the research notes behind them, including what the page leaves out. Public copy: Substrate, research/offensive-ai-harnesses-2026-11 and Data/Offensive-AI-Harnesses. Use tags (2026-11-16): every harness carries tags from a fixed set of seven, from its own README (verbatim sentence) or from attack reporting (the report).

Thesis (2026-11-17): attackers have been seen using fourteen open-source agent harnesses (nine confirmed, five observed), out of 154 we track (the other 140 are the roster in data/field.json, with GitHub facts in data/field-stats.json). What moved since 2026-11-16: Strix is now CONFIRMED (Gambit, 2026-09-22: it was the vulnerability-search stage of a retail card-theft operation that compromised 27+ companies; the report ties no breach to Strix itself, so its Breach cell reads "Discovery only"). Hermes Agent went from one failed-exploit case to four operations (Gambit, Acronis, CloudSEK, plus Unit 42) and now carries a breach. Cairn gained Gambit and NorForge, CyberStrikeAI gained TrendAI, ARTEX gained six reports (Check Point, Datadog, Unit 42, Amazon, Microsoft on two North Korean actors, GMO). Three harnesses are new to the table, all OBSERVED: CyberStrike and HalberdStrike (both in Acronis's BOSSAI report) and AntiFox (Arctic Wolf, which words the tie as infrastructure "associated with" intrusions). HexStrike AI stays OBSERVED: GTIG's Oct 30 report names it once among frameworks abused in incident response, its Nov 16 report calls what it saw "experimentation", and Acronis (2026-11-04) found it installed on a lone operator's attack node and wired into every agent that needed it but ties no breach to it. DeepAudit is OBSERVED: Talos lists it among UAT-10147's intrusion frameworks but did not see it used on victims. Left out of the field table on purpose: CAI (source-available, research-only terms), pentestMCP (no license), AgentHound (no LLM in the loop). Since mid-October, multi-agent pentest frameworks (ARTEX, Cairn) run whole intrusions at machine speed against old weaknesses; Unit 42: autonomy raised volume and coverage, not complexity. FBI FLASH-20261113-001: some ARTEX intrusions went from first targeting to privileged access in under three hours; 1,600+ exposed ARTEX consoles in early November.

Original thesis (2026-09-19): attackers have used at least seven open-source agent harnesses in real operations, but Claude Code is the harness named most often. Agents mostly do recon and vulnerability validation; humans still finish when exploitation fails. GTIG: "not yet observed" fully autonomous pipelines against targets. Unit 42: only 12 of 405 AI-enabled malware samples showed up in customer telemetry.

Evidence tiers:
- CONFIRMED: a primary vendor/IR/government report shows use in a real operation.
- OBSERVED/PARTIAL: deployed against real targets, breach not stated, or honeypot only.
- FORUM: sold or discussed on criminal forums.
- NO INTRUSION: widely covered, no documented attack.

## B. Commercial coding agents used as the harness

- Claude Code — the most-named harness.
  - GTG-2002 (Anthropic, 2025-08-27): data extortion against ≥17 orgs (healthcare, emergency services, government, religious); tactics kept in a CLAUDE.md file; ransom demands $75k–$500k+ in Bitcoin; no encryption.
  - GTG-1002 (Anthropic, 2025-11-13): Chinese state-sponsored (high confidence); ~30 targets; "a handful" of validated intrusions; Claude executed "80-90% of tactical operations independently"; humans at 4–6 decision points; Claude Code orchestrating sub-agents over MCP servers wrapping open-source pentest tools. Caveat from Anthropic itself: Claude "frequently overstated findings and occasionally fabricated data."
  - Anthropic Sept 2026: GTG-20006 (Russian, "JackPoterz", Midnight-Blizzard-consistent; 20+ orgs in Ukraine/Europe; AI rebuilt malware after detection), GTG-50014 (ShinyHunters affiliates; admin in ~3 hours; ~200 downstream SaaS customers; a terabyte exfiltrated), GTG-10007 (Chinese "exploit foundry" in Changsha; ~50 orgs; agent swarms; ~a dozen possible zero-days in one month).
  - GTIG Sept 2026: UNC6240 / ShinyHunters with Claude Code + custom MCP tools.
  - Gambit Aug 2026: suspected The Gentlemen ransomware affiliate — recon, credential theft, VPN backdoors, lateral movement, exfiltration across several orgs.
- Gemini CLI — "Patriot Bait" operator (Russian-speaking) built and deployed a botnet C2 in ~six minutes. Trend Micro, 2026-07-14.
- Codex — Zerofot (Gambit). OpenAI's own four threat reports (Jun 2025–Jun 2026) mention no Codex or agent-mode misuse.
- CC Switch — PRC pipeline driving Claude, Gemini, Codex; GTIG says construction/experimentation only.
- The victim's own AI CLIs — Nx "s1ngularity" npm attack (2025-08-26): malicious Nx versions ran Claude Code, Gemini CLI and Amazon Q with permission prompts disabled to hunt for secrets; results pushed to public "s1ngularity-repository" repos. GitGuardian: 2,349 secrets from 1,079 repos in phase 1. Wiz: guardrails refused ~25% of Claude calls. GTIG QUIETVAULT stealer (Nov 2025) did the same.
- Miasma worm (StepSecurity, 2026-06-05): planted .claude/settings.json and .gemini/settings.json SessionStart hooks, a Cursor rule and a VS Code task in Azure repos; GitHub disabled 73 repos across four Microsoft orgs. The agent's config became the execution path.
- Custom, unnamed agent frameworks — JADEPUFFER (Sysdig, 2026-07-01): LLM agent exploited Langflow CVE-2025-3248, stole creds, moved to Nacos/MySQL, encrypted/destroyed a database; honeypot. Mandiant case: cloud credentials harvested in under six hours. Unit 42 (2026-09-02): extortion intrusion, 50+ ATT&CK techniques.
