# Harnesses in the Wild — content of record (as of 2026-11-16; first compiled 2026-09-19)

The page and its machine-readable dataset render from data/ (evidence.json, field.json, sources.json, uses.json); this file holds the research notes behind them, including what the page leaves out. Public copy: Substrate, research/offensive-ai-harnesses-2026-11 and Data/Offensive-AI-Harnesses. Use tags (2026-11-16): every harness carries tags from a fixed set of seven, from its own README (verbatim sentence) or from attack reporting (the report).

Thesis (2026-11-16): attackers have been seen using eleven open-source agent harnesses (eight confirmed, three observed), out of a field of 57 we track (the other 46 are the roster in data/field.json, with GitHub facts in data/field-stats.json). HexStrike AI stays OBSERVED: GTIG's Oct 30 report names it once among frameworks abused in incident response, and its Nov 16 report calls what it saw "experimentation". DeepAudit is OBSERVED: Talos lists it among UAT-10147's intrusion frameworks but did not see it used on victims. Left out of the field table on purpose: CAI (source-available, research-only terms), pentestMCP (no license), AgentHound (no LLM in the loop). Since mid-October, multi-agent pentest frameworks (ARTEX, Cairn) run whole intrusions at machine speed against old weaknesses; Unit 42: autonomy raised volume and coverage, not complexity. FBI FLASH-20261113-001: some ARTEX intrusions went from first targeting to privileged access in under three hours; 1,600+ exposed ARTEX consoles in early November.

Original thesis (2026-09-19): attackers have used at least seven open-source agent harnesses in real operations, but Claude Code is the harness named most often. Agents mostly do recon and vulnerability validation; humans still finish when exploitation fails. GTIG: "not yet observed" fully autonomous pipelines against targets. Unit 42: only 12 of 405 AI-enabled malware samples showed up in customer telemetry.

Evidence tiers:
- CONFIRMED: a primary vendor/IR/government report shows use in a real operation.
- OBSERVED/PARTIAL: deployed against real targets, breach not stated, or honeypot only.
- FORUM: sold or discussed on criminal forums.
- NO INTRUSION: widely covered, no documented attack.

## A. Open-source attack harnesses with documented real-world use

8. ARTEX (Go, multi-agent planner/worker; released on GitHub July 2026; developer closed the repo in October 2026, forks, archives and a commercial ARTEX PRO continue) — Tier: CONFIRMED.
   - VAPOR PANDA (China-nexus espionage, a.k.a. Earth Estries): from 2026-10-17, one ARTEX controller against 200+ organizations in 14+ countries over 11 days; confirmed post-exploitation at nine (BLOODALCHEMY deployed). CrowdStrike, 2026-10-29. https://www.crowdstrike.com/en-us/blog/vapor-panda-uses-artex-to-scale-global-campaign/
   - Unnamed Chinese-speaking, financially motivated actor: South Korean financial firms, late Sep–early Oct 2026, PII of ~67,000 people exfiltrated. Zscaler ThreatLabz, 2026-10-14. https://www.zscaler.com/blogs/security-research/threat-actor-abuses-agentic-ai-pentesting-framework-target-south-korean (CrowdStrike on the same campaign, 2026-10-07: https://www.crowdstrike.com/en-us/blog/unknown-threat-actor-uses-artex-to-target-south-korean-finance/)
   - Storm-0940 (Microsoft: "China-state aligned"): after compromising ConnectWise application credentials, ARTEX activity against 2,250+ downstream Microsoft 365 tenants. Storm-3358 (Cambodia-based, financially motivated, Southeast Asian finance). Both as summarized by Cisco Talos, 2026-11-13: https://blog.talosintelligence.com/artex-and-beyond/ (Microsoft's own page not read: the search for it was blocked.)
   - FBI FLASH-20261113-001 (TLP:CLEAR), 2026-11-13: in use since at least August 2026 across finance, government, tech, defense, semiconductor, energy, healthcare and more. https://www.ic3.gov/CSA/2026/261113.pdf
   - Unit 42 IR also saw ARTEX in multiple intrusions: https://unit42.paloaltonetworks.com/artex-and-ai-powered-red-teaming-tools/
9. Cairn (open-source multi-agent pentest framework, OODA loop over a shared blackboard; not Talos's unrelated CAIRN malware tracker) — Actor: CL-STA-1238 (China-nexus intelligence collection, moderate confidence). Source: Unit 42, 2026-11-12. Aug–Sep 2026: 25 operations against at least 19 organizations (semiconductor, US defense policy, civil society) from a customized fork with an "AIScan Runner Skills" pack, on Zhipu GLM 5.2 and DeepSeek V4; unauthorized access or data retrieval at 10, including 1M+ member records at a US teachers' union. Tier: CONFIRMED. https://unit42.paloaltonetworks.com/cairn-framework-ai-autonomous-attacks/ — GTIG, 2026-11-16, separately observed Cairn used against targets including US aerospace: https://cloud.google.com/blog/topics/threat-intelligence/agentic-threat-activity-crosses-a-significant-threshold
10. CyberStrikeAI (open-source, Go; LLM orchestrator and C2 in one server process; AIPentest/CyberStrikeAI) — Kaspersky Securelist, 2026-11-02: confirmed victims in the education sector across Africa and Latin America; implant deployed after a SQL Server compromise; agent deployment to domain-admin compromise in 3–4 days; DCSync and Golden Ticket; database export; Kaspersky could not link the activity to a known group. Tier: CONFIRMED. https://securelist.com/tr/cyberstrikeai-attacks/121715/ — CERT-In CICA-2026-3651, 2026-11-04, names it with the ARTEX family, PentAGI and Cairn in the CRAFTY FALCON campaign against Indian financial firms: https://www.cert-in.org.in/s2cMainServlet?CACODE=CICA-2026-3651&pageid=PUBADV01 (GTIG 2026-11-16 had only seen experimentation.)

## B. Commercial coding agents used as the harness

- Claude Code — the most-named harness.
  - GTG-2002 (Anthropic, 2025-08-27): data extortion against ≥17 orgs (healthcare, emergency services, government, religious); tactics kept in a CLAUDE.md file; ransom demands $75k–$500k+ in Bitcoin; no encryption.
  - GTG-1002 (Anthropic, 2025-11-13): Chinese state-sponsored (high confidence); ~30 targets; "a handful" of validated intrusions; Claude executed "80-90% of tactical operations independently"; humans at 4–6 decision points; Claude Code orchestrating sub-agents over MCP servers wrapping open-source pentest tools. Caveat from Anthropic itself: Claude "frequently overstated findings and occasionally fabricated data."
  - Anthropic Sept 2026: GTG-20006 (Russian, "JackPoterz", Midnight-Blizzard-consistent; 20+ orgs in Ukraine/Europe; AI rebuilt malware after detection), GTG-50014 (ShinyHunters affiliates; admin in ~3 hours; ~200 downstream SaaS customers; a terabyte exfiltrated), GTG-10007 (Chinese "exploit foundry" in Changsha; ~50 orgs; agent swarms; ~a dozen possible zero-days in one month).
  - GTIG Sept 2026: UNC6240 / ShinyHunters with Claude Code + custom MCP tools.
  - Gambit Aug 2026: suspected The Gentlemen ransomware affiliate — recon, credential theft, VPN backdoors, lateral movement, exfiltration across several orgs.
- Gemini CLI — "Patriot Bait" operator (Russian-speaking) built and deployed a botnet C2 in ~six minutes. Trend Micro, 2026-07-14.
- Codex — Zerofot (Gambit). OpenAI's own four threat reports (Jun 2025–Jun 2026) mention no Codex or agent-mode misuse.
- CC Switch — PRC pipeline driving Claude, Gemini, Codex; GTIG says construction/experimentation only.
- The victim's own AI CLIs — Nx "s1ngularity" npm attack (2025-08-26): malicious Nx versions ran Claude Code, Gemini CLI and Amazon Q with permission prompts disabled to hunt for secrets; results pushed to public "s1ngularity-repository" repos. GitGuardian: 2,349 secrets from 1,079 repos in phase 1. Wiz: guardrails refused ~25% of Claude calls. GTIG QUIETVAULT stealer (Nov 2025) did the same.
- Miasma worm (StepSecurity, 2026-06-05): planted .claude/settings.json and .gemini/settings.json SessionStart hooks, a Cursor rule and a VS Code task in Azure repos; GitHub disabled 73 repos across four Microsoft orgs. The agent's config became the execution path.
- Custom, unnamed agent frameworks — JADEPUFFER (Sysdig, 2026-07-01): LLM agent exploited Langflow CVE-2025-3248, stole creds, moved to Nacos/MySQL, encrypted/destroyed a database; honeypot. Mandiant case: cloud credentials harvested in under six hours. Unit 42 (2026-09-02): extortion intrusion, 50+ ATT&CK techniques.

## C. Hugging Face as infrastructure
- LAMEHUG / PROMPTSTEAL — APT28 (UAC-0001). CERT-UA#16039, 2025-07-17. Malware asked Qwen2.5-Coder-32B-Instruct through the Hugging Face API to write Windows recon commands, against Ukrainian executive-branch bodies. GTIG: first observed malware querying an LLM in live operations.
- TrustBastion Android RAT (Bitdefender, early 2026) — second-stage payloads on an HF dataset, regenerated about every 15 minutes, 6,000+ commits.
- Malicious models — JFrog (Feb 2024): ~100 code-executing models, mostly PoCs, one real reverse shell. ReversingLabs "nullifAI" (Feb 2025): 2 models evading Picklescan.
- HF Spaces secrets breach (disclosed 2024-05-31).
